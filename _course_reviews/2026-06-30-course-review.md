# 2026 年春季修課心得

### 電腦系統專題

- 學分：3 學分
- 授課教師：張原豪
- 學期成績：A+
- 上課內容：
  
  &emsp;&emsp;這門課的內容主要介紹研究方法與論文閱讀技巧，不過除了前幾週的課程之外，其餘大部分時間皆由同學輪流進行論文報告。由於時間因素，本學期每位同學只需上台報告三篇論文。學期成績的計算方式如下：

  - **出席（14%）**：本學期共有 14 週安排同學報告，因此需出席這 14 週並聆聽其他同學的報告。出席情況以投票紀錄為準，每缺席一次扣總成績 1%。

  - **口頭報告（30%）**：需進行三次論文報告，每次佔總成績 10%。原則上只要完成報告，通常不會額外扣分。

  - **閱讀心得（16%）**：需以投影片形式繳交八篇論文的閱讀心得，每篇佔總成績 2%。論文需選自近三年的頂級國際會議。

  - **期末書面報告（20%）**：將八篇閱讀心得加以整理與統整，並進一步探討可能的研究方向。
 
  值得一提的是，上述項目加總後僅占總成績的 80%，剩餘的 20% 並未特別說明，推測可能是作為彈性給分，或者單純是某種「送分」。


- 心得：

  &emsp;&emsp;這門課的主要目的是培養新進研究生閱讀、整理與分析論文的能力。透過這門課，我也因此更加認真地閱讀論文，從中獲益良多。不僅讓我對研究領域有了更廣泛且更深入的認識，也為日後持續閱讀與進行研究奠定了良好的基礎。


### 自然語言處理(NLP)

- 學分：3 學分
- 授課教師：陳信希
- 學期成績：A+
- 上課內容：

  &emsp;&emsp;這門課主要介紹現代自然語言處理的基本概念與技術，內容涵蓋 tokenization、embedding、N-gram language model、neural language model、large language model、Transformer、post-training、masked language model，以及 multi-LLM agent 系統等主題。整體而言，課程內容相較於「深度學習之應用」來得較為基礎，但在 multi-LLM agent 系統的探討上則更加深入。這門課的評分標準主要包含以下幾個部分，不過各項成績所占的總比重似乎並未明確說明，最後也沒有公佈所有項目的成績。

  - **期中考與期末考**：以問答題為主，考試範圍包含課堂內容；其中期末考除了授課內容之外，也涵蓋其他同學的論文報告內容。

  - **論文閱讀報告**：以分組方式進行，需報告近兩年自然語言處理領域的頂級會議論文。此部分的成績又細分為三項：25% 為向助教進行演練報告的表現，50% 為正式上台報告的表現，其餘 25% 則為書面投影片的品質。

  - **期末專題報告**：以分組方式針對一個公開的大方向進行探討。本學期的主題與情緒相關，專題內容包含一份提案以及兩次與助教的討論。評分方式分為兩部分，其中 45% 為與助教討論時的表現，剩餘 55% 則依據最終繳交的書面報告評分。


- 心得：

  &emsp;&emsp;這學期的課程內容大多與「深度學習之應用」有所重疊，因此學習起來相對輕鬆。不過也因為許多內容與過去接觸過的知識相近，課堂本身帶來的新知相對有限。儘管如此，學期後半段著重介紹 LLM agent 的相關應用，讓我更了解當代大型語言模型的發展趨勢與實際應用方式。

  &emsp;&emsp;我認為這門課收穫較多的部分，主要來自期末的論文閱讀報告與期末專案。在論文閱讀報告中，我們選擇了一篇利用 LLM agent 進行 RAG reranking 的研究，透過閱讀與整理這篇論文，我更了解 LLM agents 在應用層面的多樣性。除此之外，在期末專案中，我們選擇驗證情緒對大型語言模型推理能力的影響，也讓我對 LLM 行為分析與實驗設計有更進一步的認識。此外，這次期末專案中有相當多程式碼是透過 LLM 輔助生成與修改完成的，因此這也可以視為我實際使用 LLM agent 協助研究與開發的一次嘗試。透過這個過程，我更具體地體會到 LLM 在程式撰寫、除錯與實驗流程建立上的實用性。



### 智慧型汽車導論

- 學分：3 學分
- 授課教師：林忠緯
- 學期成績：A+
- 上課內容：

  &emsp;&emsp;上課內容涵蓋智慧型車輛系統的各個組成面向，包括通訊、感測（sensing）、感知（perception）以及規劃（planning）等主題。學期初較著重於系統設計與時序分析（timing analysis），因為這些議題與系統安全性息息相關。而在後半學期，課程則介紹了 Intersection Management，探討如何進行路口通行的排程（scheduling），以及相關衝突檢測演算法的設計。本學期的評分方式如下：

  - **作業（10%）**：共有兩次作業，每次佔總成績 5%，內容主要讓學生熟悉課堂中介紹的演算法與方法。

  - **期末考（50%）**：於第 11 週舉行，題型包含排序問題、是非題以及分析與推導題。

  - **期末專題口頭報告（10%）**：需報告期末專題的目前進度，或提出研究構想與實驗規劃。

  - **期末專題書面報告（30%）**：為期末專題的最終成果報告，主題可從論文閱讀與調查（survey）、系統實作（implementation）以及研究探索（research）等方向切入，也可以結合多種形式進行。


- 心得：

  &emsp;&emsp;這門課的內容與「系統專題研究——物聯網中介軟體設計」有一定程度的重疊。不過，兩門課的側重點仍有所不同：這門課較偏向數學理論與模型方法的介紹，而系統專題研究則涵蓋較多系統設計與實作細節。相較之下，我當時對系統專題研究中的具體內容掌握得並不算完整，因此這門課也讓我有機會重新整理相關概念。在期末報告中，我們選擇研究如何透過 Vision Language Model（VLM）進行交通安全理解。具體而言，我們需要訓練一個模型，使其能針對交通影片產生與交通安全情境相關的標題，藉此評估模型對影片中事件與風險的理解能力。此外，這次報告中的主要程式也大多是透過 LLM agent 輔助生成與修改完成的，因此這也是我實際使用 LLM agent 協助專案開發的一次經驗。
